# Project Overview

# Project Title

AI Content Marketing Using UGC Ads

### Business

PetalPop Bouquet – Hyderabad

### Objective

Create AI-generated UGC advertisement content for a bouquet business using prompt engineering and AI tools.

## Target Audience

- Couples
- Students
- Working Professionals
- People looking for thoughtful gifts

## Problem Solved

Many people struggle to find meaningful gifts for special occasions or last-minute surprises.

## Solution

PetalPop Bouquet provides customized bouquets that help customers express emotions, celebrate special moments, and create memorable experiences.

## Deliverables

- Scroll-stopping hooks
- UGC ad scripts
- Instagram Reels content
- Facebook ad content
- YouTube Shorts content
- CTA variations
- AI-generated promotional video

## Tools Used

- ChatGPT
- Runway AI
- Canva
- GitHub
- Google Gemini
